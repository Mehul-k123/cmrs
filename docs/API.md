# API Reference

Interactive docs (OpenAPI 3, generated by drf-spectacular):

- Swagger UI: `/api/docs/`
- ReDoc: `/api/redoc/`
- Raw schema: `/api/schema/`

Base path `/api/`. JSON in and out. Monetary values are **decimal strings** (`"1500.50"`).

## Authentication

```http
POST /api/auth/login/      {"username": "agent.ravi", "password": "Demo@1234"}
→ 200 {"access": "...", "refresh": "...", "user": {...role, branch...}}
```

Send `Authorization: Bearer <access>` on every request. The access token lives 30 minutes and the refresh token 1 day; refresh tokens rotate and the old one is blacklisted.

| Method | Path | Notes |
|---|---|---|
| POST | `/auth/login/` | Throttled (10/min per IP) |
| POST | `/auth/refresh/` | `{"refresh"}` → new pair |
| POST | `/auth/logout/` | Blacklists the refresh token |
| GET | `/auth/me/` | Current user |
| GET/POST/PATCH | `/auth/users/` | Admin writes; others list within their scope |

## Errors

Every error uses the same envelope:

```json
{ "code": "over_collection", "message": "Amount ₹13000.00 exceeds the outstanding ₹12000.00 ...", "details": {"outstanding": "12000.00"} }
```

| HTTP | When |
|---|---|
| 400 | Validation (`validation_error`, with per-field `details`) or a business rule (`over_collection`, `discrepancy_reason_required`, …) |
| 401 | Missing or expired token |
| 403 | Role not allowed for the action |
| 404 | Not found **or outside your scope** |
| 405 | Method not supported (e.g. PATCH on a collection) |
| 409 | Conflict: `possible_duplicate`, `duplicate_bank_reference`, `already_reviewed`, `idempotency_key_reused` |

## Endpoints

List endpoints are paginated (`?page=`, `?page_size=` up to 200) and support `search=` and `ordering=`.

### Master data
| Method | Path | Roles | Filters |
|---|---|---|---|
| GET/POST/PATCH | `/branches/` | read: all (scoped), write: Admin | |
| GET/POST/PATCH | `/customers/` | read: all (scoped), write: Admin, BM | `branch`, `assigned_agent` |
| GET/POST | `/loans/` | read: all (scoped), create: Admin, BM | `customer`, `branch`, `agent`, `status` |
| GET | `/loans/{id}/schedule/` | scoped | Installments with balance and overdue flag |
| GET | `/loans/{id}/repayments/` | scoped | Repayment history |

### Collections
| Method | Path | Roles | Notes |
|---|---|---|---|
| GET | `/collections/` | all (scoped) | `date_from`, `date_to`, `branch`, `agent`, `status` (multi), `mode`, `loan` |
| POST | `/collections/` | Agent | **Header `Idempotency-Key` required.** Body `{loan, amount, collected_at?, notes?, confirm_duplicate?}`. 201 new, 200 idempotent replay |
| GET | `/collections/daily/?date=` | all (scoped) | Totals by status, cash in hand, rows |
| GET | `/collections/{id}/` | scoped | Includes installment allocations |
| POST | `/collections/{id}/reverse/` | Admin, BM (BM: unlocked only) | `{reason}` |

### Branch reconciliation
| Method | Path | Roles | Notes |
|---|---|---|---|
| GET | `/submissions/` | all (scoped) | `date_from`, `date_to`, `branch`, `agent`, `status` |
| POST | `/submissions/` | Agent | `{collection_ids: [..], declared_amount?, note?}` |
| GET | `/submissions/{id}/` | scoped | With items |
| POST | `/submissions/{id}/approve/` | BM, Admin | `{received_amount, note}`. A note is required when there is a difference |
| POST | `/submissions/{id}/reject/` | BM, Admin | `{reason}` |
| GET | `/discrepancies/` | Admin, Finance, BM | `type`, `status`, `branch`, `agent`, dates |
| POST | `/discrepancies/{id}/resolve/` | Admin, Finance, BM | `{note}` |

### Bank deposits & settlement
| Method | Path | Roles | Notes |
|---|---|---|---|
| GET | `/deposits/` | Admin, Finance, BM | `status`, `branch`, `delayed=true`, dates on `deposit_date` |
| POST | `/deposits/` | BM, Admin | `{submission_ids, bank_name, account_number, reference_number, deposit_date, amount, mismatch_reason?}` |
| POST | `/deposits/{id}/settle/` | Finance, Admin | `{settled_amount, settled_on, settlement_reference, note?}` |
| POST | `/deposits/{id}/fail/` | Finance, Admin | `{reason}` |

### Digital payments (mock gateway)
| Method | Path | Roles | Notes |
|---|---|---|---|
| GET/POST | `/payments/intents/` | all (scoped) | `{loan, amount}` → intent + `payment_url` |
| POST | `/payments/intents/{id}/simulate/` | scoped | `{outcome: success\|failure}`: fires a signed webhook |

### Reporting
| Method | Path | Roles | Notes |
|---|---|---|---|
| GET | `/dashboard/summary/` | all (auto-scoped) | `date_from`, `date_to` (default last 30 days, max 1 year), `branch`, `agent`, `status`. Returns `kpis`, `lifecycle`, `trend`, `by_branch`, `by_agent`, `discrepancies_by_type` |
| GET | `/audit-logs/` | Admin, Finance | `entity_type`, `entity_id`, `action`, `actor`, dates |

## Example: full lifecycle with curl

```bash
API=http://localhost:8000/api
tok() { curl -s -X POST $API/auth/login/ -H 'Content-Type: application/json' \
  -d "{\"username\":\"$1\",\"password\":\"Demo@1234\"}" | python3 -c 'import sys,json;print(json.load(sys.stdin)["access"])'; }
AGENT=$(tok agent.ravi); BM=$(tok bm.mumbai); FIN=$(tok finance)

# 1. collect
curl -s -X POST $API/collections/ -H "Authorization: Bearer $AGENT" -H "Idempotency-Key: $(uuidgen)" \
  -H 'Content-Type: application/json' -d '{"loan": 1, "amount": "1500.00"}'
# 2. submit (use the collection id from step 1)
curl -s -X POST $API/submissions/ -H "Authorization: Bearer $AGENT" -H 'Content-Type: application/json' \
  -d '{"collection_ids": [<id>]}'
# 3. approve with a ₹100 shortage
curl -s -X POST $API/submissions/<sid>/approve/ -H "Authorization: Bearer $BM" -H 'Content-Type: application/json' \
  -d '{"received_amount": "1400.00", "note": "short at count"}'
# 4. deposit
curl -s -X POST $API/deposits/ -H "Authorization: Bearer $BM" -H 'Content-Type: application/json' \
  -d '{"submission_ids":[<sid>],"bank_name":"HDFC Bank","account_number":"5020001","reference_number":"UTR123","deposit_date":"2026-10-18","amount":"1400.00"}'
# 5. settle
curl -s -X POST $API/deposits/<did>/settle/ -H "Authorization: Bearer $FIN" -H 'Content-Type: application/json' \
  -d '{"settled_amount":"1400.00","settled_on":"2026-10-18","settlement_reference":"STMT-1"}'
```
